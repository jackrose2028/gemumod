Nintendo 64 games
=================

Put Nintendo 64 ROM files (or .zip files containing them) in this folder.
They appear on the home page and in the game page's "Game" dropdown.

After adding or removing files, refresh the list with:
    node tools/generate-rom-index.mjs
On GitHub this runs automatically (see .github/workflows/update-indexes.yml).
When you play locally with start-windows.bat or serve.py, new files show up without it.

Only add games you have the right to use and share: this folder is public on GitHub Pages.
