## What it is

Short instructions for the optional minified build.

## How it works

## Why it exists

Minifying reduces load time and bandwidth for production.

## Notes

- The command written there (`node run minify`) is a typo. The working command is `npm run minify` (or `node minify/minify.js`), as in `package.json` and the main README.
