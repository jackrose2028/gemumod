## What it is

The release-style changelog in Markdown (about 50 KB). Newest entry is `4.3.0-local.6`, followed by the upstream version history.

## How it works

- Each local release is a numbered list of changes. The top entry lists the 15 performance features (stats overlay, performance mode, render scale, run-ahead, refresh-rate adaptation, audio latency, per-game profiles, battery saver, core prefetch).
- Older sections carry the upstream EmulatorJS changelog so history is preserved.

## Why it exists

Keeps a dated, version-by-version history in the conventional place, complementing the narrative in `ENHANCEMENTS.txt`.
