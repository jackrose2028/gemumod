## What it is

A single ~116 KB ES-module bundle of Nostalgist.js (MIT, by arianrhodsandlot), modified to run this site's local EmulatorJS core builds. Exports `Nostalgist`.

## How it works

- Generated by `tools/nostalgist-mod/build.mjs` from the TypeScript in `tools/nostalgist-mod/src`. Do not edit by hand.
- Nostalgist wraps RetroArch compiled to WebAssembly: it resolves ROM/BIOS/core files, builds RetroArch's virtual file system and config, boots the Emscripten module on a canvas and exposes methods such as `launch`, `pause`, `resume`, `saveState`, `loadState`, `saveSRAM`, `screenshot`, `press`, cheats and `resize`.
- The modifications make it read cores from `data/cores/*.7z` (extracted with `data/compression/extract7z.js`, guided by the manifest), feed input through EmulatorJS's `simulate_input` export, and avoid CDN fetches.

## Why it exists

Provides a second, lighter engine. It has a small footprint and a simple canvas UI, and demonstrates that the same core archives can be driven by a different frontend.
