## What it is

The game list for `data/NES/`. Currently `{"files": []}`, meaning no games are installed.

## How it works

- Generated by `tools/generate-rom-index.mjs`: an array of `{name, size}` objects sorted naturally. `assets/folders.js` fetches it (on GitHub Pages) when it cannot read a live directory listing.
- Once empty, the platform is shown on the home page as an empty folder with a hint to add ROMs.

## Why it exists

GitHub Pages and similar static hosts cannot list directory contents, so a pre-built index is the only way the site can discover games.
