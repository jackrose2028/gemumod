## What it is

Index of the supplied core archives (about 18 KB). Generated by `tools/generate-core-manifest.mjs`.

## How it works

- `files`: 187 archives with their byte sizes, e.g. `81-wasm.7z`, `81-thread-wasm.7z`, `beetle_vb-legacy-wasm.7z`. 46 cores have 4 variants (plain, legacy, thread, thread-legacy); `dosbox_pure` and `ppsspp` have only threaded variants, because they require threads.
- `cores`: 48 entries, each with the display name, supported file extensions, `defaultWebGL2` and `supportsMouse`.
- The browser reads it to know which systems are playable, which variant to request (WebGL2 vs legacy, threaded vs not), and uses the size as `?v=` cache-buster.

## Why it exists

A static site cannot list a folder, and trying variants blindly would cause 404s. The manifest makes core selection exact and offline-friendly.
